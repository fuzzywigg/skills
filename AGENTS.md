# AGENTS.md — skills

## Classification
- Tier: B=Maintained
- Autonomy: L1=Bounded agent
- Stack: Shell, Markdown

## Purpose
Curated Claude Code skills (.claude directory files) for real engineering workflows — shared publicly from the fuzzywigg ecosystem for community use.

## Safe Agent Actions
- Update skill documentation and descriptions
- Fix typos or improve clarity in skill files
- Add new skill files that follow existing conventions

## Escalate to Human
- Removing or renaming existing skills (breaks external references)
- Changes to skill trigger conditions or core behavior
- Any skill that touches secrets, credentials, or destructive operations
